# NEXORA, Brand Identity et Design System

Outil de référence pour toute la communication et les futures créations de NEXORA. Il a été établi à partir du site (nexoraa-nu.vercel.app) et de son code source.

| Dossier | Contenu |
|---|---|
| `01-BRAND-BOOK/` | `NEXORA-Brand-Book-v1.pdf` (34 pages, 16:9) et `NEXORA-Brand-Book-v1.md` (version éditable) |
| `02-LOGO-BRAND-ASSETS/svg/` | 18 déclinaisons vectorielles : monogramme NX (couleur, os, braise, monochromes, icônes), mot-signature NEXORA, logo complet |
| `02-LOGO-BRAND-ASSETS/png/` | Les mêmes déclinaisons en PNG haute définition (2048 px, fonds transparents conservés) |
| `02-LOGO-BRAND-ASSETS/favicon/` | `favicon.ico`, `favicon.svg`, PNG 16, 32, 48, 180 (Apple), 192 et 512 |
| `03-COLOR-PALETTE-TYPOGRAPHY/` | Planche visuelle de synthèse (2400 × 1500), palettes, familles, échelle typographique, éléments graphiques |
| `04-DESIGN-SYSTEM/` | `NEXORA-Design-System.md` et planches des composants et des états |
| `05-DESIGN-TOKENS-SOURCE-FILES/` | `nexora-tokens.css`, `nexora-tokens.json`, `logo.tsx`, `icons.tsx`, `site-globals.css` |

Légende utilisée dans les documents : **Observé** = relevé sur le site ou dans son code ; **Recommandé** = proposition à valider.

Polices : Archivo, Instrument Serif et JetBrains Mono, toutes trois gratuites sur Google Fonts (licence SIL Open Font).
